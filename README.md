# 🛒 E-commerce Sales Data Analysis

A SQL-driven data analytics project that explores an e-commerce transactional dataset to uncover insights around customer behavior, sales trends, seller performance, and revenue growth. The project loads raw CSV data into a MySQL database using Python, then answers 15 business questions (basic, intermediate, and advanced) using SQL, and visualizes the results with Python.

---

## 📌 Project Overview

E-commerce companies generate large volumes of transactional data — orders, payments, products, customers, and sellers. This project simulates the role of a **Data Analyst** tasked with turning that raw data into actionable business insights.

The workflow covers the full analytics pipeline:

1. **Data Ingestion** – Load raw CSV files into a relational (MySQL) database.
2. **Data Querying** – Write SQL queries ranging from basic aggregations to advanced window functions.
3. **Data Analysis & Visualization** – Use Python (Pandas, Seaborn, Matplotlib) to process query results and visualize trends.
4. **Business Insight Generation** – Answer real-world business questions about sales, customers, and sellers.

---

## 🗂️ Dataset

The dataset used is the **Target E-commerce Dataset** from Kaggle, containing multiple relational tables such as `customers`, `orders`, `order_items`, `products`, `payments`, `sellers`, and `delivery`.

🔗 **Source:** [Kaggle - Target Dataset](https://www.kaggle.com/datasets/devarajv88/target-dataset?select=products.csv)

## ⚙️ How It Works

### 1. Load Data into MySQL
`csv_to_sql.py` reads each CSV file, infers appropriate SQL data types, creates the corresponding table, and inserts the records into a MySQL database.

```bash
python csv_to_sql.py
```

> Update the database credentials and folder path inside the script before running.

### 2. Run the Analysis
Open `Ecommerce_SalesDataAnalysis_Project.ipynb` in Jupyter Notebook. The notebook connects to the MySQL database and executes SQL queries to answer the business questions below, visualizing key results with Seaborn/Matplotlib.

## ❓ Business Questions Answered

### Basic Queries
1. List all unique cities where customers are located.
2. Count the number of orders placed in 2017.
3. Find the total sales per category.
4. Calculate the percentage of orders paid in installments.
5. Count the number of customers from each state.

### Intermediate Queries
1. Calculate the number of orders per month in 2018.
2. Find the average number of products per order, grouped by customer city.
3. Calculate the percentage of total revenue contributed by each product category.
4. Identify the correlation between product price and purchase frequency.
5. Calculate total revenue generated by each seller and rank them.

### Advanced Queries
1. Calculate the moving average of order values for each customer.
2. Calculate the cumulative sales per month for each year.
3. Calculate the year-over-year growth rate of total sales.
4. Calculate customer retention rate (repeat purchase within 6 months).
5. Identify the top 3 customers by spend in each year.

---

## 📊 Key Insights

- **Bed, Bath & Table**, **Health & Beauty**, and **Computer Accessories** are the top revenue-generating product categories.
- Nearly **100% of orders** involve installment-based payments, highlighting a strong customer preference for flexible payment plans.
- **São Paulo (SP)** and **Rio de Janeiro (RJ)** dominate the customer base by a wide margin over other states.
- Total sales showed strong **year-over-year growth**, with 2018 continuing the upward trend from 2017.
- Product price and purchase frequency showed a **weak negative correlation**, suggesting price alone isn't a strong driver of purchase volume.
